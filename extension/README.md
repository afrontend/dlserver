# 동네 도서관에서 찾기 (크롬 확장)

웹에서 본 책 제목을 드래그해 [동네 도서관](https://dongne.afrontend.dev/)에서 바로 찾는 크롬 확장입니다.
같은 일을 하는 북마클릿은 사이트 맨 아래 "📚 동네 도서관" 버튼입니다.

## 쓰는 법

- 제목을 드래그하고 우클릭 → **📚 동네 도서관에서 "…" 찾기**
- 또는 제목을 드래그하고 툴바의 확장 아이콘을 누릅니다. 선택이 없으면 사이트만 엽니다.

새 탭에서 `https://dongne.afrontend.dev/?title=<제목>&ref=ext` 가 열립니다. 도서관은 넣지 않으므로 사이트가
내 도서관(그 사이트에서 최근에 검색한 도서관 최대 5곳)에서 찾고, 내 도서관이 없으면 제목만 채워 둡니다.
GA 에서는 `entry_ref=ext` 로 구분됩니다.

## 설치 (압축해제된 확장 프로그램)

1. `chrome://extensions` 를 엽니다.
2. 오른쪽 위 **개발자 모드** 를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension/` 폴더를 고릅니다.
4. 툴바의 퍼즐 아이콘에서 "동네 도서관에서 찾기" 를 고정하면 아이콘이 보입니다.

코드를 고친 뒤에는 `chrome://extensions` 에서 새로고침(↻)을 누릅니다.

## 권한

| 권한 | 쓰는 곳 |
|---|---|
| `contextMenus` | 우클릭 메뉴 |
| `activeTab`, `scripting` | 툴바 아이콘을 눌렀을 때만 그 탭의 선택한 텍스트를 읽습니다 |

페이지 내용을 미리 읽거나 다른 곳으로 보내지 않습니다. 빌드 과정은 없습니다 (순수 JS, Manifest V3).

## 구성

| 파일 | 내용 |
|---|---|
| `manifest.json` | 확장 설정 |
| `background.js` | 우클릭 메뉴·툴바 아이콘 처리 |
| `searchUrl.js` | 검색 주소 만들기 (테스트: `searchUrl.test.js`, `npm run test:server` 에 포함) |
| `icons/` | 사이트 로고(`public/logo.jpg`)의 책 더미를 잘라 만든 16·32·48·128px 아이콘 |
